Bootstrap 5

Sitio web desarrollado con **HTML y Bootstrap 5**, donde exploramos una forma más eficaz de dar diseño a una página web mediante el uso de **clases predefinidas** en lugar de escribir todo el CSS a mano.

🔗 **Demo (GitHub Pages):** https://22carlosnarvaez.github.io/taller-3_html/

---

## 🎯 Objetivos del taller

- Aplicar estilos y componentes de **Bootstrap 5** usando sus clases.
- Construir un diseño ordenado y adaptable (responsive) a distintos tamaños de pantalla.
- Enlazar **Git** con **VS Code** y trabajar con un repositorio propio.
- Enviar cambios a GitHub desde la **consola** (`add`, `commit`, `push`).
- Publicar el proyecto con **GitHub Pages**.

---

## 📁 Estructura del proyecto

```
taller-3_html/
├── app/              # Páginas y/o scripts de la aplicación
├── assets/           # Recursos estáticos (imágenes, estilos, íconos, etc.)
├── index.html        # Página principal
├── repositorio.html  # Página con la información del repositorio
└── README.md         # Documentación del proyecto
```

| Elemento | Descripción |
|---|---|
| `app/` | Contiene los archivos propios de la aplicación. |
| `assets/` | Recursos estáticos que usan las páginas. |
| `index.html` | Punto de entrada del sitio. |
| `repositorio.html` | Página complementaria enlazada desde el sitio. |
| `README.md` | Este documento. |

## 🚀 Cómo ejecutarlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/22CarlosNarvaez/taller-3_html.git
   ```
2. Entra a la carpeta:
   ```bash
   cd taller-3_html
   ```
3. Abre `index.html` en tu navegador (o usa la extensión **Live Server** de VS Code).


## 📚 Aprendizajes

- Bootstrap permite lograr un diseño óptimo y consistente solo combinando clases.
- Organizar el proyecto en carpetas (`app`, `assets`) facilita su mantenimiento.
- Trabajar con Git desde VS Code y la consola es la base del control de versiones.
